# AI News Aggregator showcase

This folder contains the visual showcase video for AI News Aggregator, captured from the local production build on August 31, 2026.

## Included assets

- `raw/raw-showcase.webm` — original full Playwright capture, preserved as the reusable editing source.
- `raw/raw-showcase.mp4` — full H.264 conversion of the preserved capture for convenient future editing.
- `edit/` — named editorial takes with source intervals documented in `edit/README.md`.
- `ai-news-aggregator-showcase.mp4` — short product walkthrough in 1440×900, encoded as H.264 with `yuv420p` and fast start for browser compatibility.

## Flow shown

1. Select TechCrunch, MarkTechPost, MIT Tech Review, VentureBeat, and The Verge.
2. Open the feed after the articles load.
3. Filter the feed to TechCrunch.

The video contains only public article content and the product interface; no personal or secret data is included.
