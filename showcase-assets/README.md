# AI News Aggregator showcase

This folder contains the canonical visual showcase for AI News Aggregator and historical editing sources.

## Canonical asset

- `ai-news-aggregator-showcase.mp4` — current public walkthrough, encoded as H.264 with `yuv420p` and fast start for browser compatibility.
- Stable public URL: `https://raw.githubusercontent.com/LeoneMarcos/AI-News-Aggregator/main/showcase-assets/ai-news-aggregator-showcase.mp4`

The stable URL is reused by the project README, GitHub profile, and portfolio. Consumers should reference this URL instead of copying the video or creating a new attachment URL.

## Historical/editing assets

- `raw/` — preserved earlier capture sources.
- `edit/` — named editorial takes with source intervals documented in `edit/README.md`.
- `raw-auto/` and `screenshots/` — generated by the automated publishing workflow when it runs.

## Flow shown

1. Select TechCrunch, MarkTechPost, MIT Tech Review, VentureBeat, and The Verge.
2. Open the feed after articles load.
3. Filter the feed to TechCrunch.

The automated capture mocks RSS proxy responses with deterministic public demonstration data so showcase generation does not depend on live external feeds.

## Publishing

Use the **Publish Showcase** GitHub Actions workflow when a change materially affects the public product walkthrough. The workflow records the browser flow, converts it to the canonical MP4, preserves review evidence as an artifact, and commits the updated canonical media only when it changed.

Routine UI changes do not require publication of a new canonical showcase; temporary visual-review evidence should be used for development validation instead.
